# DIMA CAD — 설치파일(.exe) 만들기

웹앱이 아니라 **설치형 데스크톱 앱(Windows 설치파일)** 으로 빌드하는 방법입니다.
Electron + electron-builder(NSIS) 를 사용합니다. 빌드된 앱은 **완전 오프라인**으로 동작하며,
내부 HTTP 서버(COOP/COEP 헤더 포함)로 화면을 띄우기 때문에 **STP/STEP(WASM)도 정상 동작**합니다.

## 사전 준비 (한 번만)
1. Node.js LTS 설치: https://nodejs.org (설치 시 기본 옵션)
2. 이 폴더(`AUTO-CAD-TOOL`)에서 명령 프롬프트(cmd) 또는 PowerShell 열기

## 빌드 절차
```bat
cd /d "C:\Users\cwd10\AUTO-CAD-TOOL"
npm install          :: electron, electron-builder 설치 (최초 1회, 인터넷 필요)
npm run dist         :: Windows 설치파일(NSIS) 생성
```

## 결과물
- `dist\DIMA CAD Setup 1.0.0.exe`  ← 이 파일이 **설치파일**입니다.
- 설치파일 실행 → 설치 경로 선택 → 바탕화면/시작메뉴 바로가기 생성 → "DIMA CAD" 실행

## 빌드 전 미리 실행해 보기 (설치 없이 테스트)
```bat
npm start
```
→ Electron 창이 떠서 설치된 앱과 동일하게 동작합니다.

## 참고
- electron-builder는 최초 1회 electron/NSIS 구성요소를 내려받습니다(인터넷 필요).
  이후 빌드 및 **설치된 앱 실행은 오프라인**으로 가능합니다.
- AI Review(Gemini)만 인터넷이 필요합니다. (DIMA 분석·STP·DXF는 모두 오프라인)
- 기존 `DIMA.exe`(C# HTTP 서버) / `▶ DIMA 실행.bat` 도 그대로 사용 가능합니다.
  이번 작업은 그 위에 "정식 설치형 앱" 옵션을 추가한 것입니다.
- 아이콘을 바꾸려면 `build/icon.ico`(256x256 포함 .ico)를 만들고 package.json의
  `build.win` 에 `"icon": "build/icon.ico"` 를 추가하세요.
