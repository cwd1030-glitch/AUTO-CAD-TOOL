# Injection Verification Tool — 사용자 매뉴얼

## 설치
1. `Injection Verification Tool_1.0.0_x64-setup.exe` 실행
2. 설치 경로 선택(기본 `C:\Program Files\Injection Verification Tool`)
3. 설치 완료 후 바탕화면 아이콘 또는 시작 메뉴에서 실행
4. 별도의 로그인·인증·시리얼 입력 없음 — 즉시 사용 가능

## 화면 구성
- 상단 탭: **대시보드 / 2D 도면 검증 / 3D 사출 분석 / 통합 리포트**
- 대시보드: 최근 분석의 KPI(검증 모델 수, 예측 불량, 위험 항목, 사이클 타임), 종합 점수, 불량 유형, 위험 항목 요약

## 3D 사출성형 검증
1. **[3D 사출 분석]** 탭 → 모델 업로드 (`.stl`, `.stp`, `.step`, `.obj`)
   - STEP/STP 도 내부 occt 엔진으로 실제 메쉬 테셀레이션 후 정밀 분석합니다.
2. 소재 선택 → 자동으로 DFM 검증 수행
   - 검사 항목: 두께, Draft, 언더컷, Gate, Weld Line, Sink Mark, Warpage, Shrinkage
3. 3D 뷰어 색상: 🟢 정상 / 🟡 주의 / 🔴 수정 필요
4. 모델 우클릭 → Gate(주입구) 추가 → 유동/냉각/싱크마크 시뮬레이션
5. 결과는 **대시보드**와 **통합 리포트**에 자동 반영

## 2D 도면 검증
- **[2D 도면 검증]** 탭 → `.dxf` / `.dwg` 업로드 → 분석 시작
- (DWG 변환은 로컬 AutoCAD 설치 시 지원)

## 리포트
- **[통합 리포트]** 탭에서 분석 종합 결과 확인
- PDF 내보내기(헤더의 📄 버튼)

## 오프라인 / 무설치 동작
- **별도 설치 불필요**: Python 등 사전 설치 없이 설치 후 즉시 동작합니다(솔버가 단독 exe로 내장).
- 인터넷 없이 CAD 열기·DFM 검증·솔버 연산·프로젝트 확인이 가능합니다.
- 멀티-AI 리뷰 등 외부 API 기능만 인터넷이 필요합니다.

## 문제 해결
- **STP 로딩 실패**: AP214/AP242 형식 STEP 권장, 또는 STL로 변환 후 업로드
- **3D 분석이 느림/멈춤**: 대용량(>300mm급) 모델은 메모리·시간이 크게 늘 수 있습니다(고해상도 복셀). 모델을 단순화하거나 분할 검토를 권장합니다.
- **CAD 정리**: 하단 콘솔의 'CAD 정리' 버튼으로 백그라운드 AutoCAD 프로세스 종료
