# CADMOULD식 메쉬 설정 기반 DIMA 개발 목표

## 목표
DIMA의 최종 목표는 CADMOULD처럼 3D CAD/메쉬를 먼저 정상적으로 준비하고, 그 메쉬 품질을 기준으로 사출 해석을 실행하는 프로그램이다. 단순히 STL을 화면에 띄우는 수준이 아니라, 해석 가능한 메쉬인지 확인하고, 게이트/공정/재료 조건을 연결한 뒤, 유동, 냉각, 수축, 변형, 웰드라인, 싱크마크 리스크를 검증한다.

## 핵심 사용자 흐름
1. 사용자가 STL 또는 STEP 파일을 업로드한다.
2. 프로그램이 형상 중심 정렬, 단위/크기 추정, 표면 삼각형 상태, watertight 여부, 비정상 삼각형, 경계 엣지, 복셀 해상도를 검사한다.
3. 메쉬 상태를 `통과`, `경고`, `실패`로 표시하고, 실패 시 해석을 무리하게 진행하지 않고 수정 가이드를 보여준다.
4. 사용자가 게이트 위치, 재료, 금형 방향, 수지 온도, 금형 온도, 사출 속도, 압력 한계를 설정한다.
5. Python 물리 솔버가 복셀 기반 충전/냉각/변형 해석을 수행한다.
6. 다중 알고리즘 예측 계층이 선형 회귀, 결정 트리, 랜덤 포레스트 방식의 예측값과 앙상블 불확실성을 함께 산출한다.
7. 결과는 대시보드, 3D 오버레이, 리포트, JSON/CSV/Excel 내보내기로 제공한다.

## 메쉬 설정 요구사항
- CAD 원점이 멀리 떨어진 모델은 로드 직후 자동 중심 정렬한다.
- STEP 모델은 브라우저에서 테셀레이션된 메쉬를 STL 바이너리로 변환해 Python 복셀 솔버에 전달한다.
- 메쉬 품질 항목은 최소한 다음을 포함한다.
  - 삼각형 수와 정점 수
  - watertight 여부
  - normal/winding 일관성
  - 비정상 또는 0면적 삼각형 수
  - 경계 엣지와 non-manifold 엣지
  - 모델 크기와 최소 치수 대비 복셀 셀 수
  - 복셀화된 유효 cavity 셀 수
- 최소 두께 방향에 복셀 셀이 4개 미만이면 해석 신뢰도 경고를 표시한다.
- 메쉬 실패 상태에서는 사용자가 `강제 해석`을 선택하지 않는 한 최종 리포트에 경고를 남긴다.

## 정확도 고도화 방향
- 현재 구현은 물리 기반 Python 솔버와 로컬 검증 보정값을 결합한다.
- 새 예측 계층은 `numpy_multi_algorithm_ensemble`로 시작한다.
  - 선형 회귀: 공정 입력과 형상 지표의 전역 경향을 빠르게 반영한다.
  - 결정 트리: 두께, 게이트 수, 압력 한계 같은 임계 조건을 구간별로 반영한다.
  - 랜덤 포레스트: 여러 트리의 평균으로 국소 조건 편향을 줄인다.
- 실제 Moldflow 또는 시사출 데이터가 들어오면 기준 앵커 대신 검증 데이터셋으로 학습하도록 확장한다.
- TensorFlow/PyTorch는 충분한 실측 데이터가 확보된 뒤, 딥러닝 기반 품질 예측 모델로 추가한다. 데이터가 없을 때 딥러닝 결과를 실제 검증값처럼 표시하지 않는다.

## 패키지화 요구사항
- 개발 PC에서는 `development\build-python.ps1`로 Python 솔버 exe를 빌드한다.
- 최종 배포는 Tauri/NSIS 기반 Setup.exe를 목표로 한다.
- 최종 사용자 PC에는 Python, pip, Node.js 설치를 요구하지 않는 형태가 목표다.
- 설치 파일에는 실행 파일, Python 솔버 번들, 사용자 매뉴얼, 검증 리포트 템플릿, 샘플 STL을 포함한다.

## 출력 요구사항
- 3D 대시보드: 메쉬 품질, 사출 조건, 결함 위치, 신뢰도, 보정 상태 표시
- 리포트: 점수, 주요 결함, 메쉬 품질, 공정 조건, 보정 데이터, 다음 조치 표시
- 데이터 내보내기: JSON, CSV, Excel 형식 지원
- 품질 검증용 원본 데이터는 예측값과 분리하여 저장한다.
