# DIMA 3D 사출물 검증기 마케팅 콘텐츠

## 유튜브 영상 구성안

### 제목 후보
- 사출 금형 검토 시간을 줄이는 3D 사출물 검증기, DIMA
- STEP/STL 모델만 넣으면 사출성형 리스크를 한 화면에서 확인
- 싱크, 수축, 변형, 언더컷을 빠르게 검토하는 제조성 분석 툴

### 60초 소개 영상 스크립트
3D 모델을 받았는데, 사출 전에 어디가 위험한지 빠르게 확인해야 할 때가 있습니다.
DIMA 3D 사출물 검증기는 STEP 또는 STL 모델을 불러와 구배, 언더컷, 싱크, 수축, 변형, 냉각 리스크를 한 화면에서 검토할 수 있게 도와줍니다.

분석 결과는 단순 점수로 끝나지 않습니다.
게이트 조건, 소재, 공정 온도, 사출 속도, 압력 한계를 함께 반영하고, 결과 신뢰도와 주요 위험 항목을 대시보드로 보여줍니다.

기술자는 빠르게 설계 리스크를 찾고, 일반 사용자는 대시보드와 리포트를 통해 어떤 부분을 수정해야 하는지 이해할 수 있습니다.
금형 제작 전에 더 많이 확인하고, 시사출 전에 더 적게 놓치는 것.
DIMA는 사출물 검토 과정을 더 빠르고 명확하게 만드는 3D 제조성 검증 도구입니다.

### 영상 장면 구성
1. 문제 제기: 모델은 있는데 사출 리스크 판단이 어렵다
2. 파일 업로드: STEP/STL 모델 불러오기
3. 3D 분석 화면: 구배, 수축, 싱크, 변형, 냉각 오버레이
4. 신뢰도 대시보드: 점수, 위험도, 신뢰도, 권고 사항
5. 리포트: 검토 결과 공유
6. 마무리: 설계 검토와 금형 검토 시간을 줄이는 도구

## 웹사이트 콘텐츠

### 히어로 카피
3D 사출물 검토를 더 빠르고 신뢰성 있게.

STEP/STL 모델을 불러와 사출성형 리스크를 분석하고, 구배, 언더컷, 싱크, 수축, 변형, 냉각 위험을 한 화면에서 확인하세요.

### 핵심 기능
- 3D 모델 기반 사출성형성 분석
- 소재별 수축률과 공정 조건 반영
- 구배, 언더컷, 파팅, 코어 검토
- 싱크마크, 수축, 변형, 냉각 위험 예측
- 게이트 자동 후보 및 유동 분석 보조
- 분석 신뢰도와 표본 기반 결과 표시
- 대시보드 및 리포트 중심의 검토 흐름

### 신뢰도 강조 문구
DIMA는 단순히 결과를 색으로 보여주는 도구가 아닙니다.
분석 표본 수, 게이트 조건, 공정 입력값을 기반으로 결과 신뢰도를 함께 표시하여 사용자가 결과를 더 신중하게 판단할 수 있게 설계되었습니다.

### 대상 사용자
- 금형 설계자
- 사출 엔지니어
- 제품 설계자
- 제조 검토 담당자
- STEP/STL 모델을 빠르게 검토해야 하는 실무자
